# TrainerFace

Aplicação web para registrar e consultar treinos por data usando Supabase.

## Configuração

1. Abra o projeto no Supabase.
2. Vá em SQL Editor.
3. Execute `database/schema.sql`.
4. Abra `index.html` em um servidor local ou publique no Vercel/GitHub Pages.
5. As credenciais públicas do projeto já estão configuradas em `js/supabase.js`.

A chave utilizada é uma publishable key. Não coloque uma `service_role` ou outra chave secreta no frontend.

## Publicação rápida

No Vercel, importe este projeto como um projeto estático. Não é necessário Node.js para esta versão.
